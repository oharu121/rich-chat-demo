# 2026-01-01 - Add `/rag` Slash Command

## Overview

Adding a new `/rag` slash command that queries an external RAG (Retrieval-Augmented Generation) endpoint and displays responses with source citations.

## Reference Implementation

Pattern adapted from `/Volumes/MacUSB/repository/discord-gemini-bot/src/ai/rag.py`:
- `RAGClient` class for async HTTP communication
- SSE streaming for real-time token delivery
- Source citation formatting from retrieved chunks

## Design

### Architecture

```
User types "/rag What is X?"
    ↓
Frontend selects RAG agent
    ↓
POST /api/chat { agent: "rag", message: "What is X?" }
    ↓
RAGAgent.stream_response()
    ↓
RAGClient.query() → External RAG API
    ↓ (SSE stream)
Yield: status, tokens, sources
    ↓
Display answer with source citations
```

### RAG API Contract

**Request:**
```json
POST {RAG_API_URL}/api/chat
{
  "message": "user query",
  "history": [],
  "document_set": "original",
  "strategy": "standard",
  "use_reranking": false
}
```

**Response (SSE):**
- `event: chunks` → `{ "chunks": [{ "filename", "start_line", "end_line" }] }`
- `event: token` → `{ "token": "word" }`
- `event: done` → `{}`
- `event: error` → `{ "message": "..." }`

### Source Citation Format

```
**Sources:**
- `filename.txt:45-120`
- `other.md:10-25`
```
