# 2026-01-02: Travel Planning Slash Command

## Decision: CrewAI for Multi-Agent Framework

### Frameworks Evaluated

| Framework | Verdict | Reason |
|-----------|---------|--------|
| **AutoGen** (Microsoft) | Rejected | Too complex, enterprise-focused, transitioning to new framework |
| **Google ADK** | Runner-up | Good Gemini integration but newer, smaller community |
| **LangGraph** | Considered | Powerful state machines but steeper learning curve |
| **OpenAI Agents SDK** | Considered | Clean but less mature than CrewAI |
| **CrewAI** | Selected | Role-based simplicity, perfect for travel planning |

### Why CrewAI

- Intuitive "crew of specialists" metaphor matches travel planning perfectly
- Lightweight Python integration with FastAPI backend
- Large community (1M+ downloads, 100K+ developers)
- YAML configuration for clean agent definitions
- LiteLLM integration works with Gemini

### Implementation

- `/travel` slash command routes to `TravelAgent`
- 4-agent crew with sequential execution:
  1. **Research Agent** - Destinations, attractions, weather, culture
  2. **Itinerary Planner** - Day-by-day scheduling
  3. **Budget Analyst** - Cost estimation and money-saving tips
  4. **Logistics Coordinator** - Transportation and accommodation

### SSE Status Updates

The travel agent emits status updates as each crew member works:
- `"researching destinations"` - Research Agent
- `"planning itinerary"` - Itinerary Planner
- `"calculating budget"` - Budget Analyst
- `"finding logistics"` - Logistics Coordinator

### Usage

```
/travel Tokyo, Japan
/travel Paris for 5 days
/travel Budget trip to Bali
```
